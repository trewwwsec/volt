# Security Policy

## Supported Versions

Security fixes are applied to the latest release line.

| Version | Supported |
| --- | --- |
| Latest tag | Yes |
| Older tags | No |
| `main` (pre-release) | Best effort |

## Reporting a Vulnerability

If you discover a security issue in `volt`, report it privately before public disclosure.

Please include:

- A clear description of the issue and impact.
- Reproduction steps (minimal command/path).
- Affected version/tag/commit.
- Suggested mitigation if available.

Preferred channel:

- Open a private security advisory in the repository (GitHub Security Advisories), if enabled.

Fallback channel:

- Contact the maintainers privately if a direct contact path is published.
- If no private channel is available, open a public issue with minimal detail and request private follow-up.

## Disclosure Expectations

- We aim to acknowledge reports within 3 business days.
- We aim to provide a remediation plan or triage outcome within 10 business days.
- Please avoid publishing proof-of-concept details until a fix or mitigation is available.
